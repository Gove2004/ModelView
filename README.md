# ModelView · 模型视图

基于 **PySide6** 的悬浮式模型提供商管理工具:一块不遮挡桌面的**贴边双翼面板**,
管理 OpenAI 兼容的模型提供商,并在本地提供 OpenAI 兼容的转发代理,方便其他
软件快速切换模型服务。

> 只支持 **OpenAI 兼容格式** 请求,不做 Claude / Response 等其他格式的转换。

## 界面布局(形态 B · 贴边悬浮)

```
┌────────────────────────────────────────────┐
│              ● ●  顶部胶囊开关              │ ← 代理启停(绿=运行/灰=停止)
├──────────────┐             ┌───────────────┤
│              │             │               │
│  左翼 · 提供商 │             │  右翼 · 模型树  │
│  (卡片+增删改) │             │  (树状折叠/双击 │
│              │             │   复制模型名)   │
│              │  桌面可见区   │               │
├──────────────┘             └───────────────┤
│            ▓▓ 日志条(toast 风格,可滚动)      │ ← 底部渐隐式消息流
└────────────────────────────────────────────┘
```

- 四块无边框、实心深色、圆角悬浮面板,贴屏幕左右两侧 / 顶部中央 / 底部中央。
- 不设半透明,不遮任务栏与桌面操作区;所有面板随托盘菜单或 **Ctrl+Alt+M** 整体滑入 / 滑出。
- 提供商列表的**新增 / 编辑**收在无边框小弹层(屏幕正中心)中;卡片操作直接铺在卡片上,无需右键。
- 左右两栏顶部各带搜索框,支持即时筛选。

## 功能

| 功能 | 说明 |
| --- | --- |
| 提供商管理 | 左翼卡片**直显操作**: 编辑 / 复制 URL / 删除(双击卡片也可编辑);所有提供商一律平等 |
| 搜索筛选 | 左翼按提供商 name/url 筛选、右翼按提供商名或模型名筛选,匹配根节点自动展开 |
| 多路路由 | 所有已配置的提供商都可被路由: 客户端模型名填 `name:model` 即转发到对应提供商(自动去掉前缀) |
| 模型探测 | 右翼点 **刷新** 并发探测**所有**提供商,树状折叠展示 `name:model`(双击模型即复制) |
| 本地转发 | 本地 `127.0.0.1:10901` 提供 OpenAI 兼容代理,支持 SSE 流式(stream=true);`/models` 自动聚合所有提供商的模型为 `name:model` |
| 开关控制 | 顶部胶囊开关启停转发服务,托盘图标 / 提示文字同步状态,并记住上次状态 |
| 全局热键 | **Ctrl+Alt+M** 随时显示 / 隐藏全部悬浮面板(不依赖窗口焦点) |
| 日志提醒 | 底部 toast 风格日志条,分级着色(成功绿 / 错误红 / 请求灰),支持上下滚动回看 |
| 托盘常驻 | 系统托盘图标常驻,右键 **隐藏面板 / 退出**;关闭即托盘化 |
| 持久化 | 配置保存在根目录 `config.json` |

## 运行(托盘程序,无控制台窗口)

```bat
:: 首次使用先装依赖(已在 .venv 虚拟环境中安装 PySide6)
.venv\Scripts\python.exe -m pip install PySide6
```

- **双击 `启动.vbs`**: 用 `.venv\Scripts\pythonw.exe` 静默启动,无黑框,托盘常驻(推荐)。
- **调试用**: 命令行执行 `.venv\Scripts\python.exe main.py`(会带控制台,便于看输出)。
- 出错时自动写入根目录 `error.log`。

## 托盘与快捷键

- **Ctrl+Alt+M**: 全局显示 / 隐藏悬浮面板(任意窗口焦点下均生效;注册失败会在日志条提示)。
- **右键托盘图标** → 菜单:**隐藏面板 / 显示面板**、**退出**。
- **双击托盘图标** → 显示 / 隐藏面板。
- 悬浮窗无边框,直接点面板空白处即可整体拖动窗口。

## 使用步骤

1. **添加提供商**: 左翼点 **+**,弹层中填写 name / url / key,保存。
   URL 示例:
   - DeepSeek: `https://api.deepseek.com/v1`
   - 本地 Ollama: `http://localhost:11434/v1`(key 可留空)
2. **探测模型**: 右翼点 **刷新**,列表树状展示各提供商的 `name:model`,双击模型名可复制;
   两栏顶部的搜索框可即时筛选。
3. **开启转发**: 点顶部中央的**胶囊开关**(变绿即运行中,端口默认 10901)。
4. **接入其他软件**: 把软件的 OpenAI Base URL 填为
   `http://127.0.0.1:10901/v1`,API Key 随意填写;模型名填
   `name:model`(如 `ds:deepseek-v4-flash`)即可路由到对应提供商,
   不同软件可以同时使用不同的提供商,无需来回切换。

## URL 拼接规则

- 提供商 URL 以 `/v1` 结尾时,客户端请求路径里的 `/v1` 前缀会自动去掉,
  避免出现 `/v1/v1`。
- 提供商 URL 不带 `/v1` 时,客户端路径原样拼接。

## 路由说明

- 配置多个提供商后,**所有提供商都能被路由**,不需要"激活"或来回切换。
- 客户端里模型名填 `name:model`(如 `ds:deepseek-chat`),代理会把请求
  转发到名为 `ds` 的提供商,并自动去掉前缀再传给上游。
- 模型名没有提供商前缀时,代理无法确定目标,会返回 400 并提示使用
  `name:model` 格式。
- 代理的 `/models` 会聚合所有提供商的模型,统一返回 `name:model` 格式,
  客户端拉取后即可选择。
- 提供商名称不能包含冒号 `:`(路由前缀分隔符)。

## 常见问题

- **端口被占用**: 换一个端口再开启,或关闭占用该端口的程序。
- **转发出错**: 看底部日志条的红色消息;全部历史在日志条中向上滚动可回看。
- **探测不到模型**: 确认 URL 和 Key 正确;本地服务(如 Ollama)需已启动。
- **请求 /models 超时**: 若提供商 URL 填成了代理自己的地址(`http://127.0.0.1:10901`),
  会造成转发自循环,现已会被拦截并提示"循环转发"。
- **安全提醒**: `config.json` 中保存了 API Key,请勿提交到公开仓库(`.gitignore` 已忽略)。
