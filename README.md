# LLM 代理工具

用 **Python + Tkinter** 编写的小工具,用于管理 OpenAI 兼容的模型提供商,
并在本地提供一个 OpenAI 兼容的转发代理,方便其他软件快速切换模型服务。

> 只支持 **OpenAI 兼容格式** 请求,不做 Claude / Response 等其他格式的转换。

## 功能

| 功能 | 说明 |
| --- | --- |
| 提供商管理 | 可保存多个提供商(name / url / key),所有提供商一律平等 |
| 多路路由 | 所有已配置的提供商都可被路由: 客户端模型名填 `name:model` 即转发到对应提供商(自动去掉前缀) |
| 模型探测 | 一键并发探测**所有**提供商,树状折叠展示 `name:model`(点箭头展开/收起,双击模型即复制) |
| 本地转发 | 本地 `127.0.0.1:10901` 提供 OpenAI 兼容代理,支持 SSE 流式(stream=true);`/models` 自动聚合所有提供商的模型为 `name:model` |
| 开关控制 | 转发服务可单独开启 / 关闭,并记住上次状态 |
| 夜晚模式 | 深色界面风格,窗口底部常驻显示提供商数量与转发开关状态 |
| 持久化 | 配置保存在 `config.json`(项目目录下) |
| 零依赖 | 仅使用 Python 标准库,无需 pip 安装任何包 |

## 运行(托盘程序,无控制台窗口)

- **双击 `启动.vbs`**: 以 `pythonw` 静默启动,无黑框,窗口出现后即常驻系统托盘。
- 也可以为 `pythonw.exe main.py` 建一个**桌面快捷方式**,效果相同。
- **调试用**: 命令行执行 `python main.py`(会带控制台,便于看输出)。
- 需要 **Python 3.8+**(官方安装包自带 tkinter;`pythonw.exe` 需在 PATH 中)。

## 托盘使用

- 点击窗口右上角 **X** → 最小化到托盘(窗口隐藏,程序继续运行)。
- **右键托盘图标** → 菜单:**显示 / 隐藏**、**退出**。
- **双击托盘图标** → 显示 / 隐藏窗口。
- 程序出错时会写入项目目录下的 `error.log`(无控制台时便于排查)。

## 使用步骤

1. **配置提供商**: 在"列表"Tab 中填写 name / url / key,点 **保存**。
   URL 示例:
   - DeepSeek: `https://api.deepseek.com/v1`
   - 本地 Ollama: `http://localhost:11434/v1`(key 可留空)
2. **探测模型**: 切到"探测"Tab,点 **探测所有提供商**,列表展示
   `name:model` 格式的模型,可一键复制。
3. **开启转发**: 切到"转发"Tab,点 **开启转发**(默认端口 10901)。
4. **接入其他软件**: 把软件的 OpenAI Base URL 填为
   `http://127.0.0.1:10901/v1`,API Key 随意填写;模型名填
   `name:model`(如 `ds:deepseek-v4-flash`)即可路由到对应提供商,
   不同软件可以同时使用不同的提供商,无需来回切换。

```
Connection/
├── main.py         # 入口: 加载配置、启动界面(无控制台,错误写入 error.log)
├── gui.py          # Tkinter 界面(夜晚模式、紧凑布局、4 个 Tab)
├── config.py       # config.json 读写(线程安全)
├── provider.py     # /models 模型探测(并发探测所有提供商)
├── proxy.py        # 本地 OpenAI 兼容转发服务(多路路由、SSE 流式、自循环拦截)
├── models.py       # /models 多提供商模型聚合缓存
├── tray.py         # 系统托盘图标(纯 ctypes,右键菜单: 显示/隐藏、退出)
├── 启动.vbs        # 静默启动脚本(无控制台窗口)
├── tests/
│   └── test_proxy.py  # 无界面冒烟测试
└── config.json     # 首次运行时自动生成
```

## URL 拼接规则

- 提供商 URL 以 `/v1` 结尾时,客户端请求路径里的 `/v1` 前缀会自动去掉,
  避免出现 `/v1/v1`。
- 提供商 URL 不带 `/v1` 时,客户端路径原样拼接。

## 路由说明

- 配置多个提供商后,**所有提供商都能被路由**,不需要"激活"或来回切换。
- 客户端里模型名填 `name:model`(如 `ds:deepseek-chat`),代理会把请求
  转发到名为 `ds` 的提供商,并自动去掉前缀再传给上游。
- 模型名没有提供商前缀时,代理无法确定目标,会返回 400 并提示使用
  `name:model` 格式。
- 代理的 `/models` 会聚合所有提供商的模型,统一返回 `name:model` 格式,
  客户端拉取后即可选择。
- 提供商名称不能包含冒号 `:`(路由前缀分隔符)。

## 常见问题

- **端口被占用**: 换一个端口再开启,或关闭占用该端口的程序。
- **转发出错**: 看"日志"Tab,会显示请求与错误信息。
- **探测不到模型**: 确认 URL 和 Key 正确;本地服务(如 Ollama)需已启动。
- **请求 /models 超时**: 若提供商 URL 填成了代理自己的地址(`http://127.0.0.1:10901`),
  会造成转发自循环,现已会被拦截并提示"循环转发"。
- **安全提醒**: `config.json` 中保存了 API Key,请勿提交到公开仓库(`.gitignore` 已忽略)。
