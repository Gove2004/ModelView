# ModelView · 模型视图

基于 **PySide6** 的悬浮式模型提供商管理工具:一块不遮挡桌面的**贴边双翼面板**,
管理 OpenAI 兼容的模型提供商,并在本地提供 OpenAI 兼容的转发代理,方便其他
软件快速切换模型服务。

> 只支持 **OpenAI 兼容格式** 请求,不做 Claude / Response 等其他格式的转换。
> 路由基于**自定义映射**(alias + provider + model),客户端模型名直接填别名
> 即可(如 `main`),切换模型在 ModelView 里改映射,不必动任何客户端配置。

## 界面布局(形态 B · 贴边悬浮)

```
┌────────────────────────────────────────────┐
│         映射  │  10901  │  复制            │ ← 顶中三段: 弹窗 / 启停 / 地址
├──────────────┐             ┌───────────────┤
│  左翼 · 提供商 │             │  右翼 · 模型树  │
│  (卡片+增删改) │             │  (单击复制纯模型名)│
│              │  桌面可见区   │               │
├──────────────┘             └───────────────┤
│       ▓▓ 日志条(默认折叠,点 [展开] 浮起)     │ ← 渐隐式消息流 + 切换
└────────────────────────────────────────────┘
```

- 四块无边框、实心深色、圆角悬浮面板,贴屏幕左右两侧 / 顶部中央 / 底部中央。
- 不设半透明,不遮任务栏与桌面操作区;所有面板随托盘菜单或 **Ctrl+Alt+M** 整体滑入 / 滑出。
- **自定义映射弹窗**、**提供商编辑弹层**均收在屏幕正中心的小弹层中;面板显隐时弹窗跟随渐显放大 / 渐隐收缩。
- 卡片操作直接铺在卡片上,无需右键;左右两栏顶部各带搜索框支持即时筛选。

## 功能

| 功能 | 说明 |
| --- | --- |
| 提供商管理 | 左翼卡片两行行尾**直显操作**: 第一行 name 尾 **修改**,第二行 url 尾 **删除**(先弹红色确认窗);所有提供商一律平等;标题实时计数 `提供商(N家)` |
| 搜索筛选 | 左翼按提供商 name/url 筛选、右翼按提供商名或模型名筛选,匹配根节点自动展开 |
| 自定义映射 | 顶栏点 **映射** 打开弹窗,每条映射 = `自定义模型名` + `提供商` + `模型`(可手填);首次预置 `main / play / test` 三个空位,可自由改名 / 删 / 增;空位和悬空位不暴露给客户端 |
| 模型探测 | 右翼点 **探测** 并发探测**所有**提供商,树状折叠展示;单击模型行即复制纯模型名(供映射弹窗粘贴);标题实时计数 `模型(N个)` |
| 本地转发 | 本地 `127.0.0.1:10901` 提供 OpenAI 兼容代理,支持 SSE 流式(stream=true);`/models` 仅返回已完整绑定的自定义映射 |
| 路由启停 | 顶中 **端口按钮**(点按启停): 灰 = 停,绿 = 运行;显示当前端口号 |
| 一键复制 | 顶中 **复制** 把 `http://127.0.0.1:<port>` 写入剪贴板,toast 提示 |
| 全局热键 | **Ctrl+Alt+M** 随时显示 / 隐藏全部悬浮面板(连带中心弹窗渐显渐隐);不依赖窗口焦点 |
| 日志 dock | 底部 toast 风格日志条,**默认折叠**仅露标题行,点 `[展开]` 沿底边向上浮起到 160px;分级着色(成功绿 / 错误红 / 请求灰),支持上下滚动回看 |
| 托盘常驻 | 系统托盘图标常驻,右键 **隐藏面板 / 退出**;关闭即托盘化 |
| 持久化 | 配置保存在根目录 `config.json` |

## 运行(托盘程序,无控制台窗口)

```bat
:: 首次使用先装依赖(已在 .venv 虚拟环境中安装 PySide6)
.venv\Scripts\python.exe -m pip install PySide6
```

- **双击 `ModelView.vbs`**: 用 `.venv\Scripts\pythonw.exe` 静默启动,无黑框,托盘常驻(推荐)。
- **调试用**: 命令行执行 `.venv\Scripts\python.exe main.py`(会带控制台,便于看输出)。
- 出错时自动写入根目录 `error.log`。

## 托盘与快捷键

- **Ctrl+Alt+M**: 全局显示 / 隐藏悬浮面板(任意窗口焦点下均生效;注册失败会在日志条提示)。
  中心弹窗(自定义映射 / 添加提供商)跟随面板一起渐显放大 / 渐隐收缩。
- **右键托盘图标** → 菜单:**隐藏面板 / 显示面板**、**退出**。
- **双击托盘图标** → 显示 / 隐藏面板。
- 悬浮窗无边框,直接点面板空白处即可整体拖动窗口。

## 使用步骤

1. **添加提供商**: 左翼点 **添加**,弹层中填写 name / url / key,保存。
   URL 示例:
   - DeepSeek: `https://api.deepseek.com/v1`
   - 本地 Ollama: `http://localhost:11434/v1`(key 可留空)
2. **探测模型**: 右翼点 **探测**,列表树状展示各提供商的可用模型;单击模型名复制其纯模型名(供下一步粘贴)。
   两栏顶部的搜索框可即时筛选。
3. **配置自定义映射**: 顶中点 **映射** 打开弹窗,每条映射 = `自定义模型名` + `提供商` + `模型`。
   首次运行预置 `main / play / test` 三个空位,可自由改名 / 删 / 增。
   `提供商` 下拉选已配置好的,`模型` 下拉从探测结果中选(也可手填);点 `新增` 加行,行尾 `删除` 移除,`保存` 落盘。
4. **开启转发**: 点顶中**端口按钮**(显示 `10901`,灰→绿表示启动)。
5. **接入其他软件**: 把软件的 OpenAI Base URL 填为
   `http://127.0.0.1:10901/v1`,API Key 随意填写;**模型名直接填自定义映射名**
   (如 `main`)即可路由到对应提供商 + 模型。
   切换模型只改 ModelView 里的映射,客户端软件不必动。

## URL 拼接规则

- 提供商 URL 以 `/v1` 结尾时,客户端请求路径里的 `/v1` 前缀会自动去掉,
  避免出现 `/v1/v1`。
- 提供商 URL 不带 `/v1` 时,客户端路径原样拼接。

## 路由说明(自定义映射)

- 每条映射 = `自定义模型名` + `提供商` + `模型`;映射保存在 `config.json` 的 `mappings` 字段。
- 客户端里模型名直接填自定义模型名(如 `main`);代理据此查找映射并转发。
- 代理 `/models` 只返回「自定义模型名 + 提供商 + 模型」三者齐全、且提供商仍存在的映射;
  未绑定的空位和指向已删除提供商的悬空位不会暴露给客户端。
- 提供商名称不能包含冒号 `:`(避免与模型名混淆)。
- **三类错误**统一返回 400 + 中文提示:
  1. 请求的模型名不在自定义映射中(提示列出当前可用别名)
  2. 该映射尚未绑定提供商和模型(空位)
  3. 该映射指向的提供商已不存在(悬空位)

## 常见问题

- **端口被占用**: 换一个端口再开启,或关闭占用该端口的程序。
- **转发出错**: 展开底部日志条(点 `[展开]`)查看红色消息;历史可向上滚动回看。
- **探测不到模型**: 确认 URL 和 Key 正确;本地服务(如 Ollama)需已启动。
- **请求 /models 超时**: 若提供商 URL 填成了代理自己的地址(`http://127.0.0.1:10901`),
  会造成转发自循环,现已会被拦截并提示"循环转发"。
- **空位 / 悬空位**: 顶中点 **映射** 打开弹窗,补全 `提供商` 和 `模型` 即可。
- **安全提醒**: `config.json` 中保存了 API Key,请勿提交到公开仓库(`.gitignore` 已忽略)。
